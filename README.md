# Projet : Landing Page

Bienvenue sur mon **deuxième projet HTML/CSS** réalisé dans le cadre du parcours [The Odin Project](https://www.theodinproject.com/).

## 📚 Contexte

Suite aux instructions fournies par le cours, l’objectif de ce projet était de **reproduire une maquette de landing page** en utilisant uniquement **HTML** et **CSS**, en mettant particulièrement l'accent sur **Flexbox** pour la mise en page.

## 🎯 Objectifs du projet

- Reproduire une structure de landing page fidèle au modèle fourni
- Mettre en pratique les bases du HTML sémantique
- Utiliser **Flexbox** pour organiser les éléments visuellement
- Structurer un projet avec plusieurs sections cohérentes
